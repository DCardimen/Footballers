# ANCHORS — where each system lives, by subsystem

The encyclopedia that used to be CLAUDE.md's anchor list, grouped by subsystem instead of by version,
with the file each anchor is in and today's names (v149 C renamed the career app; `docs/NAMES.md` maps
old → new, and old names appear here once, in parentheses, where they still show up in comments).

**Find a system:** `grep -rn "v146 E THE MENUS" src/` — banners are `/* ===== vNN NAME ===== */`. An anchor
is the text between the backticks at the start of a line below; `node scripts/anchorcheck.mjs` proves each
one still occurs in the file(s) named after the first `—` (so a renamed banner fails the smoke suite, not a
reader). History and rationale: `docs/CHANGELOG.md`. Deep dives: `docs/ARCHITECTURE.md`.

Entry format (the check parses it): `` - `ANCHOR` / `ANCHOR` — `file` + `file` · what it is ``. Put a new
entry at the TOP of its section. Hooks are `window.*` names (the public API — never renamed); checks are
`scripts/<name>.mjs` (their suites: `node scripts/run-checks.mjs --list`).

Files: `03` splash/film · `04` engine (tunables, choreographer, FieldSim) · `05` broadcast renderer ·
`07` career app (state, screens, season, prestige, the game engine `simGameV2`) · `11` pregame wizard ·
`17` pregame wheel · `18` growth wheel · `22` hub sections · `25` shell · `26` platform · `27` monetize —
all `src/NN-*.js`; `public/rib-menu*.js|css` menu + coach; `public/rib-vault*` vault. See `docs/LAYOUT.md`.
